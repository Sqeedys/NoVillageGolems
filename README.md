# No Village Golems

Disable villager-summoned iron golems while preserving player-built golems.

**[Download No Village Golems 1.0.0 for Fabric 26.3](https://github.com/Sqeedys/NoVillageGolems/raw/refs/heads/main/downloads/no_village_golems-1.0.0.jar)** · [SHA-256](downloads/SHA256SUMS.txt)

Villagers can go about their routines or panic at the sight of a zombie without summoning an iron golem. This also stops iron farms that rely on villagers to spawn their golems.

Players can still build a guardian with four iron blocks and a carved pumpkin. Iron golems already in the world continue to behave normally, and the vanilla summon command still works.

## Install on your server

1. Set up a Minecraft Java Edition **26.3** dedicated server with **Java 25** and **Fabric Loader 0.20.1** (the tested version).
2. Stop the server and put `no_village_golems-1.0.0.jar` in its `mods/` folder.
3. Start the server. Players can join with a vanilla 26.3 client. The mod works automatically and runs without Fabric API.

To restore vanilla behavior, remove the JAR and restart the server.
